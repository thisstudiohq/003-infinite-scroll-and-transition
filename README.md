## Infinite Scroll Gallery with Page Transitions

Infinite GSAP gallery with parallax scrolling, reveal animations, and Flip-powered fullscreen transitions.

[Demo](https://infinite-scroll-and-transition.netlify.app)

### Installation

Run the following commands:

```bash
bun install

bun dev
```

### Using npm

If you do not have Bun installed, delete the `bun.lock` file and run:

```bash
npm install

npm run dev
```
